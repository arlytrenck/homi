Features

Everything on one page, nothing extra.

Home-sized, not enterprise-sized. Fast, quiet, and yours.

Live status and uptime history

HTTP, TCP and ping checks with up, degraded and down states, pushed to the page over SSE. Browse 24 hours, 7, 30 and 90 days, built from hourly rollups.

Service launcher

Groups, icons, descriptions and search. Press / to find anything. Drag to reorder with touch or keyboard.

Docker auto-discovery

Label a container with homi.enable=true and it appears with its own health check.

Secure by default

Argon2id passwords, hashed sessions, CSRF checks, login rate limiting, SSRF-guarded requests, AES-256-GCM for stored secrets.

Backup and restore

YAML export and import with a dry-run preview. Your whole setup in one file.

Installable

PWA manifest, light and dark themes, and touch targets sized for phones. Multi-arch image for amd64 and arm64.

Ops view

Worst first.

A dense, NOC-style table at /ops that puts what is broken at the top. Add ?kiosk=1 for a wall display.

Status is never color alone. Every state has an icon and a word.
